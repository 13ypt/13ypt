# PDF Mistral (Hi-Res) - Install Guide

## 1. Install

Copy these 3 files to your Obsidian vault:

```
<Your Vault>/.obsidian/plugins/pdf-mistral-plugin/
  ├── main.js
  ├── manifest.json
  └── styles.css
```

## 2. Enable

- Open Obsidian Settings > Community plugins
- Turn off "Restricted mode" if needed
- Enable "PDF Mistral (Hi-Res)"

## 3. Configure

- Plugin settings > enter your **Mistral API Key**
  - Get one at https://console.mistral.ai/
- Set output folders and DPI as needed

## 4. Use

- `Ctrl+P` (or `Cmd+P`) > "Convert PDF to Markdown with images"
- Select a PDF > done!
